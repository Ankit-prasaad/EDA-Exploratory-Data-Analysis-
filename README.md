# EDA-Exploratory-Data-Analysis-
EDA (Exploratory Data Analysis) is the process of exploring and understanding a dataset before building any machine learning model or performing advanced analysis.
Objectives of EDA
Understand the structure of the dataset.
Identify missing values.
Detect duplicate records.
Find outliers.
Understand the distribution of variables.
Analyze relationships between features.
Generate insights for decision-making and modeling.

# EDA on (Cardiotocographic.csv)
